## 🚀 Featured project

### [Bibli-System](https://bibli-system.vercel.app)

A gamified Bible reading tracker with an RPG-style look, built as an installable PWA that works offline.

- Progress, XP, levels, streaks and stats are all derived from a single source of truth (the chapters marked as read), so the numbers can't drift out of sync.
- Centralized state with validated persistence in `localStorage`, ready for schema migrations.
- Unit tests covering XP, levels, streaks and progress rules.
